**Note on DownloadSentinel:** SSS 1.0.0 removed DownloadSentinel's own
download-blocking feature and warning page (user decision, 2026-11-xx).
What remains bundled is its host/domain-risk data and lookup code, which
SSS reuses for scoring the site a tab is visiting (the same engine that
used to also score downloads). If that reuse is ever removed too, delete
this row and the corresponding `lib/downloadsentinel/` files in the same
change.

Generated data files name their source in their own header. When a list
is regenerated, its source and licence stay as listed here; a new source
gets a new row in the same release.
